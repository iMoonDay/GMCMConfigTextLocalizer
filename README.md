# GMCM 配置文本本地化（GMCM Config Text Localizer）

在星露谷物语的 GMCM 配置界面中显示本地译文，支持编辑、导出与 GitHub 社区同步。

## 安装与同步

需要 SMAPI 4.1 或更高版本，以及 GMCM 1.13 或更高版本。将 `GMCMConfigTextLocalizer.dll`、`manifest.json` 和 `i18n` 文件夹放入游戏的 Mods 目录。

每次启动游戏时，模组会从 GitHub 的 `community-packs` 分支获取社区译文，并将本地缺少的条目补入安装目录下的 `overrides/<语言代码>/<模组UniqueID>.json`。已有条目不会被覆盖，包括空字符串和 `null`。已同步的译文保存在本地，离线时仍可使用。

也可以在本模组的 GMCM 配置页点击「同步社区翻译」，或在 SMAPI 控制台运行 `gmcmtext_sync`。重新打开目标模组的配置页即可查看更新。

## 管理译文

在本模组的 GMCM 设置页管理全局和单个模组的译文启用状态。关闭全局开关会暂停所有本地译文，重新开启后恢复各模组原来的启用状态。关闭某个模组的勾选框只影响该模组。设置会保存在本模组的 `config.json`。

列表显示每个模组当前语言下的有效译文数和待翻译数。默认只显示至少有一条有效译文的模组，勾选「显示全部」可查看其他已安装模组和已有本地文件的模组。未安装的模组显示灰色文件名，仍可编辑文件中的译文。

有效译文只统计非空译文，并排除标记为「无需翻译」的条目。

## 编辑译文

在目标模组的 GMCM 配置页点击右上角的「编辑译文」。编辑器的「待翻译」「无需翻译」和「全部」分类可以筛选条目，搜索框可匹配原文和译文。

选中条目后可查看原文、输入译文并实时预览。点击「应用」后更改会写入本地覆盖文件，并立即更新当前配置页。点击「取消」会丢弃尚未应用的修改。同一模组的相同原文共用一条译文。

点击「标记无需翻译」后，配置界面会继续显示原文，该条目也不会计入有效译文数、待翻译数或导出候选。标记保存在安装目录的 `overrides/.ignored/<语言代码>.json` 中，取消标记即可恢复正常处理。

「外部编辑」会用系统关联的程序打开当前模组的本地覆盖 JSON。「复制原文」会将选中条目的完整原文复制到剪贴板。

## 导出译文

在本模组的 GMCM 配置页点击「导出翻译」。左侧勾选要参与导出的模组，右侧显示所选模组的配置文本。默认启用「仅显示待翻译」并选中所有待翻译条目。

取消待翻译筛选可浏览或手动勾选其他条目。导出只会添加缺少的键，并保留已有译文。标记为「无需翻译」的条目不会进入导出候选。单个模组也可在「编辑译文」面板中点击「导出」，直接查看该模组的条目。

简体中文导出目录是 `overrides/zh/`。如果该模组已经存在 `zh-CN` 覆盖文件，编辑时会继续使用该文件。

也可以运行 `gmcmtext_export zh` 导出缺少的中文条目，附加模组 ID 可只导出指定模组。

「打开文件夹」会打开本模组的本地 `overrides` 目录。标记文件 `.ignored` 是本地管理设置，不要作为社区译文提交。

## 投稿社区译文

仓库中的 `overrides/<语言代码>/<模组UniqueID>.json` 保存社区译文，与游戏安装目录下的本地 `overrides` 文件夹分开。

```json
{
  "Enable mod": "启用模组",
  "Fish quality": "鱼的品质"
}
```

提交时只填写有效译文，不要提交空值、`null` 或「无需翻译」标记。Fork 本仓库后，将 JSON 加入或合并到对应的 `overrides/<语言代码>/` 文件，再向 `main` 分支提交 Pull Request。GitHub Actions 会校验更改，并在合并后更新游戏使用的 `community-packs` 分支。

## 构建

```powershell
dotnet build GMCMConfigTextLocalizer.csproj -c Release -p:GamePath="E:/SteamLibrary/steamapps/common/Stardew Valley"
```
